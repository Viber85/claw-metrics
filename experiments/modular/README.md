# Modular renderer v1 — test.73 preview

The production backend packages `claw_modular.py` in root and `py_modules/`. Its schema/transport stays byte-identical to `schema.py`; fixtures under `assets/modular/` match the DevLab starter documents. The Decky Layout page imports/exports validated v1 documents, selects presets and edits group geometry. Mode/document persist through saved styles; legacy styles select the classic renderer.

`enable_modular_renderer.py` installs the bounded transport, immutable exchange, background loader, measured ImGui adapter and source bridge after the existing test.72 native patches. The user-facing profile activates `claw_modular_file`; `CLAW_MODULAR_LAYOUT_FILE` remains a developer override only. Without either, no loader is constructed and the classic path is retained.

The loader reads bounded regular files off the rendering thread and retains the last valid document on failed/partial reads. Only the rendering thread accesses fonts or paints. Each prepared frame owns its readings while borrowing font atlas pointers for that frame only. Existing font reload still happens at the pre-frame boundary. JSON imports cap documents at 1 MiB, 96 nodes and 8 nesting levels; duplicate IDs, cycles, invalid ranges/colors and unknown tokens are rejected.

Production token data uses existing CPU/GPU, process/system memory, battery, frame accumulation and read-only TDP/DRAW exec sources. Disabled or unavailable readings show `--`. Numeric reservations stabilize dimensions. The first selected GPU is used. Group/element layout is nested rows/columns, not arbitrary per-element X/Y. Graphs support the six existing shape choices with a bounded 64-point history. Production gradients/outlines are reused in a measured background window; explicit root fill overrides remain respected. Vulkan supports per-command ImGui VtxOffset for documents above 64K vertices.

Checks: `python -m unittest discover -s tests`, frontend typecheck/build and node contracts, `check_modular_layout.py`, `check_modular_transport.py`, and `check_modular_imgui.py`. The ImGui check verifies pinned sources/fonts, both starter layouts and six shapes at two resolutions, and verifies stable FPS width. Its CPU rasterizer is a fixture, not Vulkan color-space or on-device verification. `test_modular_vulkan.py` runs actual lavapipe injection, live config-driven activation, invalid imports, font reload, six shapes, gradients/outline, classic fallback, reactivation and large meshes. The old Vulkan regression suite remains enabled. Device and native gamepad testing remain necessary.
